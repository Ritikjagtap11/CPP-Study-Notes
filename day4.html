9. Runtime Polymorphism, Virtual, Pure Virtual and Abstract

class Animal {
public:
    virtual void sound() { cout << "Animal"; }
};
class Dog : public Animal {
public:
    void sound() override { cout << "Dog"; }
};
class Shape {
public:
    virtual void draw() = 0;
};
VirtualPure Virtual
Can have a base implementation.Uses = 0 and contributes to making the class abstract.
Supports runtime dispatch through a suitable base pointer/reference.Derived classes are expected to implement it when making a concrete class.

15. MCQ Mock

Q1. If int *p points to x, what does *p represent?

Answer: The value stored in the object pointed to by p.

Q2. Which loop checks its condition after executing the body?

Answer: do-while.

Q3. Which constructor initializes one object from another?

Answer: Copy constructor.

Q4. Which keyword enables virtual dispatch?

Answer: virtual.

Q5. Which smart pointer represents shared ownership?

Answer: shared_ptr.

Q6. Which stream class is used for file output?

Answer: ofstream.

Q7. What marks a pure virtual function?

Answer: virtual void f() = 0;

Q8. Which STL container follows LIFO?

Answer: stack.

Q9. Which cast performs runtime checking in a polymorphic hierarchy?

Answer: dynamic_cast.

Q10. What does break do inside a loop?

Answer: It exits the loop.

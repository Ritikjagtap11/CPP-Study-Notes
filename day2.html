2. OOP: Class, Object and Core Principles

A class is a blueprint. An object is an actual instance of a class.

class Student {
public:
    string name;
    int marks;
    void display() { cout << name << " " << marks; }
};

int main() {
    Student s1;
    s1.name = "Ritik";
    s1.marks = 90;
    s1.display();
}
Encapsulation

Keep data and functions together.

Abstraction

Show essential behavior and hide unnecessary details.

Inheritance

Create a new class using an existing class.

Polymorphism

One interface/name can represent different behavior.

SpecifierMeaning
publicAccessible from outside the class.
privateAccessible inside the class; default class access.
protectedAccessible inside the class and derived classes.

3. Constructors and Destructors

A constructor runs when an object is initialized. A destructor runs when an object is destroyed.

class Student {
    int marks;
public:
    Student() { marks = 0; cout << "Constructor"; }
    ~Student() { cout << "Destructor"; }
};

Parameterized / Multiple Constructors

class Box {
public:
    Box() {}
    Box(int x) {}
    Box(int x, int y) {}
};

Different parameter lists in constructors are constructor overloading.

Dynamic Initialization

int marks;
cin >> marks;
Student s(marks);
MCQ: Constructors have the same name as the class and no return type.

4. Copy Constructor

A copy constructor creates a new object from an existing object.

class Student {
    int marks;
public:
    Student(int m) : marks(m) {}
    Student(const Student &other) {
        marks = other.marks;
    }
};
Student s1(90);
Student s2 = s1;
Think: s2 is initialized using s1.

5. Move Semantics

An lvalue normally identifies an object with a persistent location. An rvalue is commonly a temporary value.

int x = 10;       // lvalue x
int y = x + 5;    // x + 5 is a temporary value

A move constructor can transfer a resource from a movable source instead of making another resource copy.

class Buffer {
    int* data;
public:
    Buffer(int value) { data = new int(value); }
    Buffer(Buffer&& other) noexcept {
        data = other.data;
        other.data = nullptr;
    }
    ~Buffer() { delete data; }
};
CopyMove
Copies state/resource.Can transfer a resource from a movable source.
May require more work for resource-owning objects.Can avoid unnecessary resource copying.

6. Static and Constant Members

Static Data Member

class Student {
public:
    static int count;
    Student() { count++; }
};
int Student::count = 0;

Static Member Function

class Demo {
public:
    static void show() { cout << "Hello"; }
};
Demo::show();

Constant Data / Const Member Function

class Student {
    const int roll;
public:
    Student(int r) : roll(r) {}
    void display() const { cout << roll; }
};
Remember: A const member function cannot modify the object's non-mutable state through that function.

8. Virtual Base Class / Diamond Problem

In a diamond, two intermediate classes inherit from the same base and a final class inherits from both. Without virtual inheritance, the final object can contain two base subobjects.

class A { public: int value; };
class B : virtual public A {};
class C : virtual public A {};
class D : public B, public C {};
Why virtual? It provides one shared base subobject for the common base in this diamond pattern.

9. Friend Function and Friend Class

class Box {
    int value = 50;
    friend void show(Box b);
};
void show(Box b) { cout << b.value; }

A friend function is not a member function, but the class can grant it access to private/protected members.

class A {
    int x = 10;
    friend class B;
};
class B {
public:
    void show(A obj) { cout << obj.x; }
};

10. Polymorphism and Function Overloading

Polymorphism means one name/interface can represent different behavior.

class Calculator {
public:
    int add(int a, int b) { return a + b; }
    double add(double a, double b) { return a + b; }
};
Remember: Function overloading is compile-time polymorphism. Runtime polymorphism with virtual functions is Day 3.

11. Operator Overloading

class Point {

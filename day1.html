1️⃣ Session 1 — Getting Started with C++

What is C++?

C++ is a general-purpose programming language that supports procedural programming and Object-Oriented Programming (OOP). It was developed from the C language and adds features such as classes, objects, inheritance and polymorphism.

Easy idea: C++ = C-style programming + Object-Oriented Programming + many modern features.

Short history

  • C++ was developed by Bjarne Stroustrup.
  • It started as an extension of C and was originally associated with the name “C with Classes”.
  • Modern C++ has standardized versions such as C++11, C++14, C++17, C++20 and later.

C vs C++

CC++
Primarily proceduralSupports procedural + OOP
Uses structures mainly for dataHas classes and objects
No function/operator overloadingSupports function/operator overloading
No referencesSupports references
Uses malloc/freeAlso provides new/delete

Important C++ features

OOP
Classes, objects, inheritance, polymorphism.
Function Overloading
Same function name with different parameters.
References
Another name (alias) for an existing variable.
Templates
Generic programming. More detailed later.
STL
Standard Template Library containers and algorithms.
Memory Control
Pointers and dynamic memory using new/delete.

Basic C++ program structure

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World";
    return 0;
}

Line by line:

  • #include <iostream> → gives input/output facilities such as cout.
  • using namespace std; → allows writing cout instead of std::cout.
  • int main() → program execution starts here.
  • cout → prints output.
  • return 0; → indicates successful completion.

C++17

The course uses C++17 as the standard. C++17 is a version of the C++ language standard that added several modern language/library features.

Exam memory: Know the basic program structure and the purpose of #include, main(), cout, and return 0.

2️⃣ Session 2 — Tokens, Initialization, Expressions & Operators

What is a token?

A token is a smallest meaningful unit of a C++ program.

Token typeExample
Keywordint, if, return
Identifiermarks, total
Literal10, 3.14, 'A'
Operator+, ==, &&
Separator / punctuation;, ,, (), {}

Initialization

Initialization means giving a variable its initial value when it is created.

int a = 10;
double price{99.50};
char grade = 'A';
bool pass = true;

Common C++ initialization forms:

int a = 10;     // copy initialization
int b(20);      // direct initialization
int c{30};      // brace/list initialization
Remember: int x; creates a local variable without giving it a useful initial value. Prefer initializing variables explicitly.

Expression

An expression combines values, variables and operators to produce a result.

int a = 10;
int b = 20;
int sum = a + b;       // a + b is an expression

Operators

TypeOperatorsExample
Arithmetic+ - * / %a + b
Relational== != > < >= <=a > b
Logical&& || !age >= 18 && citizen
Unary++ -- + - !++a
Ternary? :max = a > b ? a : b;
Assignment= += -= *= /= %=a += 5;

Arithmetic example

int a = 10;
int b = 3;

cout << a + b << endl;  // 13
cout << a - b << endl;  // 7
cout << a * b << endl;  // 30
cout << a / b << endl;  // 3 (integer division)
cout << a % b << endl;  // 1
Important: With two integers, 10 / 3 gives 3, not 3.333... because integer division removes the fractional part.

Relational + logical example

int age = 20;
bool hasId = true;

if (age >= 18 && hasId)
    cout << "Allowed";

Ternary operator

int a = 15;
int b = 20;

int max = (a > b) ? a : b;

Meaning: if a > b is true, choose a; otherwise choose b.

Compound assignment

int x = 10;

x += 5;  // x = x + 5 → 15
x -= 3;  // x = x - 3 → 12
x *= 2;  // x = x * 2 → 24

3️⃣ Session 3 — Conditions, Loops, Jumps & Arrays

if

int marks = 75;

if (marks >= 40)
    cout << "Pass";

if-else

if (marks >= 40)
    cout << "Pass";
else
    cout << "Fail";

else-if ladder

if (marks >= 75)
    cout << "Distinction";
else if (marks >= 40)
    cout << "Pass";
else
    cout << "Fail";

switch

Use switch when one expression needs to be compared against several fixed cases.

int choice = 2;

switch (choice)
{
    case 1:
        cout << "Add";
        break;

    case 2:
        cout << "Delete";
        break;

    default:
        cout << "Invalid choice";
}
Why break? Without break, execution can continue into the next case (fall-through).

for loop

for (int i = 1; i <= 5; i++)
{
    cout << i << " ";
}

Output: 1 2 3 4 5

while loop

int i = 1;

while (i <= 5)
{
    cout << i << " ";
    i++;
}

do-while loop

int i = 1;

do
{
    cout << i << " ";
    i++;
}
while (i <= 5);
Key difference: do-while executes its body at least once because the condition is checked after the body.

break, continue, return

for (int i = 1; i <= 5; i++)
{
    if (i == 3)
        continue;     // skip 3

    if (i == 5)
        break;        // stop loop

    cout << i << " ";
}
  • break → immediately exits the loop/switch.
  • continue → skips the current loop iteration.
  • return → exits the function and can return a value.

1-D Array

An array stores multiple values of the same type in contiguous memory locations.

int marks[5] = {10, 20, 30, 40, 50};

cout << marks[0]; // 10
cout << marks[4]; // 50
Index starts from 0. For an array of size 5, valid indexes are 0, 1, 2, 3, 4.

Loop through an array

int arr[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++)
{
    cout << arr[i] << " ";
}

2-D Array

A 2-D array can be visualized like rows and columns.

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

cout << matrix[1][2]; // 6

2-D array traversal

for (int i = 0; i < 2; i++)
{
    for (int j = 0; j < 3; j++)
    {
        cout << matrix[i][j] << " ";
    }
    cout << endl;
}

Command-line arguments

C++ can receive values from the command line using argc and argv.

int main(int argc, char* argv[])
{
    cout << "Argument count: " << argc << endl;

    for (int i = 0; i < argc; i++)
        cout << argv[i] << endl;

    return 0;
}
  • argc → number of command-line arguments.
  • argv → array containing the argument strings.

4️⃣ Session 4 — Functions

What is a function?

A function is a reusable block of code designed to perform a specific task.

int add(int a, int b)
{
    return a + b;
}

int main()
{
    cout << add(10, 20);
}

Why use functions?

  • Code reuse
  • Less repetition
  • Easier testing and debugging
  • Breaks a large program into smaller tasks

Function parts

int add(int a, int b)
{
    return a + b;
}
  • int → return type
  • add → function name
  • int a, int b → parameters
  • return a + b → returned result

Function prototype

A prototype tells the compiler about a function before the function is used.

int add(int, int);  // prototype

int main()
{
    cout << add(2, 3);
}

int add(int a, int b)
{
    return a + b;
}

Common function forms

FormExample
No argument, no returnvoid show()
Argument, no returnvoid show(int x)
No argument, returnint getNumber()
Argument + returnint add(int a, int b)

Call by reference

A reference parameter lets a function work with the original variable instead of making a separate copy.

void swap(int &a, int &b)
{
    int temp = a;
    a = b;
    b = temp;
}

int main()
{
    int x = 10, y = 20;

    swap(x, y);

    cout << x << " " << y;
}

Output: 20 10

Easy memory: int &a means a is a reference/alias to the original variable.

inline function

inline suggests that the compiler may replace a small function call with the function body. It is generally used for small functions.

inline int square(int x)
{
    return x * x;
}

cout << square(5);

Math library

Mathematical functions are available through the appropriate standard library facilities, commonly using <cmath>.

#include <iostream>
#include <cmath>
using namespace std;

int main()
{
    cout << sqrt(25) << endl;  // 5
    cout << pow(2, 3) << endl; // 8
    return 0;
}

5️⃣ Sessions 5–6 — Memory Management & Pointers

Memory basics

When a program runs, variables and objects need memory. A pointer stores the address of another object or variable.

Variable
Stores a value.
int x = 10;
Address
Location of the variable in memory.
&x
Pointer
Stores an address.
int *p = &x;
Dereference
Gets the value at the stored address.
*p

Pointer example

int x = 10;

int *p = &x;

cout << x << endl;   // 10
cout << &x << endl;  // address
cout << p << endl;   // same address
cout << *p << endl;  // 10
Remember:
&x = address of x
p = address stored in p
*p = value at that address

Changing a value using a pointer

int x = 10;
int *p = &x;

*p = 50;

cout << x; // 50

Why? p points to x, so changing *p changes x.

Pointer and array

The name of an array can be used in expressions related to the address of its first element.

int arr[3] = {10, 20, 30};

int *p = arr;

cout << *p << endl;       // 10
cout << *(p + 1) << endl; // 20
cout << *(p + 2) << endl; // 30

Array traversal using pointer

int arr[5] = {10, 20, 30, 40, 50};

int *p = arr;

for (int i = 0; i < 5; i++)
{
    cout << *(p + i) << " ";
}

Array of pointers

An array can contain pointer variables.

int a = 10;
int b = 20;
int c = 30;

int *ptrs[3] = {&a, &b, &c};

cout << *ptrs[0] << endl; // 10
cout << *ptrs[1] << endl; // 20

Passing pointer to a function

void change(int *p)
{
    *p = 100;
}

int main()
{
    int x = 10;

    change(&x);

    cout << x; // 100
}

enum

An enum defines a set of named constants.

enum Day
{
    MONDAY,
    TUESDAY,
    WEDNESDAY
};

Day today = TUESDAY;
Easy idea: Instead of remembering arbitrary numeric values, you can use meaningful names.

typedef / type alias

A type alias gives another name to an existing type.

typedef unsigned int uint;

uint age = 25;

Modern C++ also supports using:

using uint = unsigned int;

uint age = 25;

Dynamic memory — new

new dynamically allocates memory.

int *p = new int;

*p = 50;

cout << *p;

You can also initialize directly:

int *p = new int(50);

delete

Memory allocated using new should be released with delete.

int *p = new int(50);

cout << *p;

delete p;
p = nullptr;
Exam concept: new allocates dynamic memory; delete releases memory allocated for one object. For an array allocated with new[], use delete[].

Dynamic array

int n = 5;

int *arr = new int[n];

for (int i = 0; i < n; i++)
    arr[i] = i + 1;

delete[] arr;
arr = nullptr;

Pointer to an object

A pointer can point to an object of a class.

class Student
{
public:
    int marks;

    void show()
    {
        cout << marks;
    }
};

int main()
{
    Student s;
    s.marks = 90;

    Student *p = &s;

    p->show();
}
Important: When using a pointer to an object, -> is used to access members through the pointer. p->marks is equivalent to (*p).marks.

this pointer

Inside a non-static member function, this points to the current object.

class Student
{
    int marks;

public:
    void setMarks(int marks)
    {
        this->marks = marks;
    }

    void show()
    {
        cout << this->marks;
    }
};

int main()
{
    Student s;
    s.setMarks(90);
    s.show();
}

Here both the parameter and data member are named marks. this->marks means the current object's member.

Smart pointers

Smart pointers help manage dynamically allocated objects automatically using ownership rules.

unique_ptr

unique_ptr represents exclusive ownership. It should not have two independent owners of the same object.

#include <memory>

std::unique_ptr<int> p = std::make_unique<int>(50);

cout << *p;
Easy idea: unique_ptr = one owner.

shared_ptr

shared_ptr allows multiple smart pointers to share ownership of the same object.

#include <memory>

std::shared_ptr<int> p1 = std::make_shared<int>(50);
std::shared_ptr<int> p2 = p1;

cout << *p1 << endl;
cout << *p2 << endl;
Easy idea: shared_ptr = shared ownership.

weak_ptr

weak_ptr observes an object managed by shared_ptr without owning it.

#include <memory>

std::shared_ptr<int> p1 = std::make_shared<int>(50);
std::weak_ptr<int> p2 = p1;

if (auto temp = p2.lock())
{
    cout << *temp;
}
Easy memory:
unique_ptr → one owner
shared_ptr → multiple owners
weak_ptr → observer, does not own

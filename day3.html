2. Runtime Polymorphism

A virtual function enables a call through a base pointer/reference to dispatch to an overriding derived implementation at runtime.

class Animal {
public:
    virtual void sound() { cout << "Animal sound"; }
};
class Dog : public Animal {
public:
    void sound() override { cout << "Bark"; }
};
Animal* p = new Dog();
p->sound();
delete p;
Key idea: Pointer type is Animal*, object is Dog. Because sound() is virtual, Dog's implementation is selected at runtime.

Pure Virtual Function

class Shape {
public:
    virtual void draw() = 0;
};

A class with at least one pure virtual function is abstract and cannot be instantiated directly.

Interface-like Design

C++ has no required separate interface keyword. A class made mainly from pure virtual functions can act as an interface-like contract.

3. Four C++ Casts

CastMain purpose
static_castSupported compile-time conversions.
dynamic_castRuntime-checked casts in polymorphic hierarchies.
const_castAdd/remove const or volatile qualification.
reinterpret_castLow-level reinterpretation.
class Base { public: virtual ~Base() {} };
class Derived : public Base {};
Base* b = new Derived();
Derived* d = dynamic_cast<Derived*>(b);
delete b;
MCQ: dynamic_cast is associated with runtime checking in a polymorphic hierarchy.

4. Exception Handling

try {
    int age;
    cin >> age;
    if (age < 0) throw age;
}
catch (int x) {
    cout << "Invalid age";
}

Flow: try → throw → matching catch.

Rethrowing

try {
    try { throw 10; }
    catch (int x) {
        cout << "Log";
        throw;
    }
}
catch (int x) { cout << "Handled again"; }

Custom Exception

class InvalidMarks {
public:
    string message;
    InvalidMarks(string msg) : message(msg) {}
};
try { throw InvalidMarks("Marks must be 0 to 100"); }
catch (InvalidMarks& e) { cout << e.message; }

6. File Handling

Write

ofstream out("students.txt");
if (out.is_open()) {
    out << "Ritik
";
    out << "Amit
";
    out.close();
}

Read

ifstream in("students.txt");
string name;
if (in.is_open()) {
    while (getline(in, name))
        cout << name << endl;
    in.close();
}
Memory: ofstream → write, ifstream → read, fstream → both.

7. Templates

Templates allow generic code to work with different types.

template <typename T>
T maximum(T a, T b) {
    return (a > b) ? a : b;
}
cout << maximum(10, 20);
cout << maximum(2.5, 1.5);

Class Template

template <typename T>
class Box {
    T value;
public:
    Box(T v) : value(v) {}
    T getValue() { return value; }
};
Box<int> b1(10);
Box<string> b2("Hello");

9. RTTI — Run-Time Type Information

RTTI provides information about an object's type at runtime.

#include <typeinfo>
class Base { public: virtual ~Base() {} };
class Derived : public Base {};
Base* p = new Derived();
cout << typeid(*p).name();
delete p;
Remember: typeid is a common RTTI feature; dynamic_cast is used for runtime-checked hierarchy casting.
